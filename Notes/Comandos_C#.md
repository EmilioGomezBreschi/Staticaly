## Comandos de Consola de C#

### Comandos Generales

- `dotnet new`: Crea un nuevo proyecto.
- `dotnet restore`: Restaura las dependencias y herramientas de un proyecto.
- `dotnet build`: Compila un proyecto y todas sus dependencias.
- `dotnet run`: Compila y ejecuta un proyecto.
- `dotnet publish`: Publica una aplicación para su implementación en un entorno de producción.
- `dotnet test`: Ejecuta las pruebas unitarias de un proyecto.
- `dotnet clean`: Limpia los archivos generados durante la compilación de un proyecto.

### Comandos de Proyecto

- `dotnet new console`: Crea un nuevo proyecto de consola.
- `dotnet new classlib`: Crea un nuevo proyecto de biblioteca de clases.
- `dotnet new web`: Crea un nuevo proyecto web.
- `dotnet new mvc`: Crea un nuevo proyecto de aplicaciones web MVC.
- `dotnet new razor`: Crea un nuevo proyecto de aplicaciones web Razor Pages.

### Comandos de Paquetes

- `dotnet add package`: Agrega un paquete al proyecto.
- `dotnet remove package`: Elimina un paquete del proyecto.
- `dotnet list package`: Lista todos los paquetes instalados en el proyecto.

### Comandos de Referencias

- `dotnet add reference`: Agrega una referencia a otro proyecto.
- `dotnet remove reference`: Elimina una referencia a otro proyecto.

### Comandos de Clases y Archivos

- `dotnet new class`: Crea una nueva clase.
- `dotnet new sln`: Crea una nueva solución.
- `dotnet sln add`: Agrega un proyecto a una solución existente.

### Comandos de Migraciones (Entity Framework)

- `dotnet ef migrations add`: Agrega una nueva migración.
- `dotnet ef migrations remove`: Elimina la última migración agregada.
- `dotnet ef database update`: Actualiza la base de datos a la última migración.

### Comandos de Pruebas Unitarias

- `dotnet test`: Ejecuta las pruebas unitarias de un proyecto.

Recuerda que estos comandos se utilizan en la línea de comandos o en la terminal, y debes estar ubicado en el directorio correcto del proyecto para ejecutarlos correctamente.

Espero que esta lista te sea útil. Si tienes más preguntas, no dudes en hacerlas.
